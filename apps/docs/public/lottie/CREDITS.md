# Lottie animations

Animations used by the docs site itself. Each file was downloaded from LottieFiles and cleaned (layer
names removed, numbers rounded).

| File          | Used by                                                  | Animation  | Author          | Source                                                   | License               |
| ------------- | -------------------------------------------------------- | ---------- | --------------- | -------------------------------------------------------- | --------------------- |
| `coffee.json` | Floating "Buy me a coffee" card (`CoffeeLauncher.astro`) | Hot Coffee | Sebastián Nieto | https://lottiefiles.com/animations/hot-coffee-DcQPM9sClO | Lottie Simple License |

`coffee.json`: the 300 x 300 canvas was cropped to 170 x 170 around the cup and its steam (layer
positions shifted to match). The colours are unchanged; `CoffeeLauncher.astro` repeats them for the still
cup shown before the animation loads.
