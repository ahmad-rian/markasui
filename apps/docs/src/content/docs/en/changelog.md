## 0.1.0 (unreleased)

First release with 75 components and 5 templates for Blade, React, and Vue.

- **Form:** Button, Input, Textarea, Select, Checkbox, Radio Group, Switch, Combobox, Input OTP, Label, Slider, Toggle, Toggle Group.
- **Feedback:** Alert, Badge, Toast, Progress, Skeleton.
- **Overlay:** Modal, Drawer, Dropdown Menu, Tooltip, Alert Dialog, Command Palette, Context Menu, Hover Card, Popover.
- **Navigation:** Tabs, Accordion, Breadcrumb, Pagination, Navbar, Navigation Menu, Sidebar, Collapsible, Menubar.
- **Data:** Card, Avatar, Table, Carousel, Code Block, Kbd, Scroll Area, Separator.
- **MarkasUI:** Bottom Navigation, Card Stack, Chat Message, Currency Input, Dock, Dynamic Island, Expandable Card, File Dropzone, Image Compare, Pinned List, Prompt Input, Theme Toggle, Tilt Card.
- **Animations:** Avatar Group, Marquee, Number Ticker, Scroll Progress, Spotlight Card, Typing Text.
- **Backgrounds:** Aurora Background, Dot Pattern, Grid Pattern, Retro Grid, Ripple Background, Stars Background.
- **Buttons:** Copy Button, Flip Button, GitHub Stars Button, Hold Button, Ripple Button, Shimmer Button.
- **Templates:** Larisa (store dashboard), Lumen (CRM workspace), Kirana (colorful customer workspace), Alur (workflow app) and Rambu (error pages: 404, 403, 419, 429, 500, 503, offline), interactive full pages in all three frameworks.

Also included:

- `markas.css` with 15 light and dark color tokens.
- Registry JSON at `/r/`, a Markdown version of every page, `llms.txt`, and `llms-full.txt`.
- The `markasui` CLI (`init`, `add`, `list`) and the `@markasui/mcp` MCP server.
- An Agent Skill in `skills/markasui`.
- Automated visual parity, axe-core, and keyboard tests for every component in all three frameworks.
- English by default, with every built-in component label available as a prop.
