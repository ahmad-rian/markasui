## 0.1.0 (belum dirilis)

Rilis pertama dengan 89 komponen dan 5 template untuk Blade, React, dan Vue.

- **Form:** Button, Input, Textarea, Select, Checkbox, Radio Group, Switch, Combobox, Input OTP, Label, Slider, Toggle, Toggle Group.
- **Feedback:** Alert, Badge, Toast, Progress, Skeleton.
- **Overlay:** Modal, Drawer, Dropdown Menu, Tooltip, Alert Dialog, Command Palette, Context Menu, Hover Card, Popover.
- **Navigasi:** Tabs, Accordion, Breadcrumb, Pagination, Navbar, Navigation Menu, Sidebar, Collapsible, Menubar.
- **Data:** Card, Avatar, Table, Carousel, Code Block, Kbd, Scroll Area, Separator.
- **MarkasUI:** Bottom Navigation, Card Stack, Chat Message, Currency Input, Dock, Drag Elements, Dynamic Island, Elastic Line, Expandable Card, File Dropzone, Float, Image Compare, Image Trail, Magnet, Pinned List, Pixel Trail, Prompt Input, Screensaver, Stacking Cards, Theme Toggle, Tilt Card.
- **Animasi:** Avatar Group, Letter Swap, Marquee, Number Ticker, Scroll Progress, Spotlight Card, Text Rotate, Text Scramble, Typing Text, Underline Link, Variable Weight Text, Vertical Cut Reveal.
- **Latar:** Aurora Background, Dot Pattern, Grid Pattern, Retro Grid, Ripple Background, Stars Background.
- **Tombol:** Copy Button, Flip Button, GitHub Stars Button, Hold Button, Ripple Button, Shimmer Button.
- **Template:** Larisa (dashboard toko), Lumen (ruang kerja CRM), Kirana (ruang kerja pelanggan berwarna), Alur (aplikasi workflow), dan Rambu (halaman error: 404, 403, 419, 429, 500, 503, offline), halaman lengkap yang interaktif di ketiga framework.

Juga termasuk:

- `markas.css` dengan 15 token warna terang dan gelap.
- Registry JSON di `/r/`, versi Markdown setiap halaman, `llms.txt`, dan `llms-full.txt`.
- CLI `markasui` (`init`, `add`, `list`) dan MCP server `@markasui/mcp`.
- Agent Skill di `skills/markasui`.
- Uji kesamaan tampilan, axe-core, dan keyboard otomatis untuk setiap komponen di ketiga framework.
- Default bahasa Inggris, dan setiap label bawaan komponen tersedia sebagai prop.
