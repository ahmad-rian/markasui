## 0.1.0 (belum dirilis)

Rilis pertama dengan 42 komponen dan 2 template untuk Blade, React, dan Vue.

- **Form:** Button, Input, Textarea, Select, Checkbox, Radio Group, Switch, Combobox, Input OTP, Label, Slider, Toggle, Toggle Group.
- **Feedback:** Alert, Badge, Toast, Progress, Skeleton.
- **Overlay:** Modal, Drawer, Dropdown Menu, Tooltip, Alert Dialog, Command Palette, Context Menu, Hover Card, Popover.
- **Navigasi:** Tabs, Accordion, Breadcrumb, Pagination, Navbar, Collapsible, Menubar.
- **Data:** Card, Avatar, Table, Carousel, Code Block, Kbd, Scroll Area, Separator.
- **Template:** Larisa (dashboard toko) dan Lumen (ruang kerja CRM), halaman lengkap yang interaktif di ketiga framework.

Juga termasuk:

- `markas.css` dengan 15 token warna terang dan gelap.
- Registry JSON di `/r/`, versi Markdown setiap halaman, `llms.txt`, dan `llms-full.txt`.
- CLI `markasui` (`init`, `add`, `list`) dan MCP server `@markasui/mcp`.
- Agent Skill di `skills/markasui`.
- Uji kesamaan tampilan, axe-core, dan keyboard otomatis untuk setiap komponen di ketiga framework.
- Default bahasa Inggris, dan setiap label bawaan komponen tersedia sebagai prop.
